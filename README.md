# SSBook Challenge

Flutter book-catalog challenge using GraphQL and GetIt, with separated data access and automated test files.

## Project scope

A study or technical-challenge implementation from its original development period. It is shared as a portfolio reference; the original implementation and commit history are preserved.

## Stack and SDK

- Flutter and Dart.
- Main declared packages: `graphql`, `get_it`, `google_fonts`, `cached_network_image`.
- Dart SDK constraint from `pubspec.yaml`: `>=2.17.1 <3.0.0`.

Use a Flutter release with a Dart SDK inside that range. Dependency modernization is a separate change from publishing this historical example.

## Run

```bash
flutter pub get
flutter run
```

## Tests

The repository contains 16 Dart test files matching `*_test.dart`. Run the existing suite with a compatible SDK:

```bash
flutter test
```

Test files are learning artifacts; their presence is not a claim that they have passed on a current Flutter release.
